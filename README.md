DoeFácil — Sistema de Gestão de Doações

Sobre o projeto:

O DoeFácil é uma aplicação desenvolvida em Java 8 puro para simular o gerenciamento de doações de alimentos, roupas e produtos de higiêne.

O projeto foi criado com o objetivo de aplicar padrões de projeto (*Design Patterns*) na prática, demonstrando organização, reutilização de código e separação de responsabilidades.

Funcionalidades:

- Cadastro e consulta de doações.
- Organização das doações por diferentes estratégias.
- Geração de resumo das quantidades cadastradas.
- Validação básica dos dados de entrada.

Padrões de projeto aplicados:

- **Singleton:** centraliza o acesso à instância do repositório de doações.
- **Facade:** simplifica o acesso às operações do sistema.
- **Strategy:** permite alternar entre diferentes critérios de organização das doações.

Tecnologias:

- Java 8
- Programação Orientada a Objetos
- Collections Framework
- Design Patterns

Como executar:

1. Clone este repositório.
2. Abra o projeto em uma IDE compatível com Java 8.
3. Execute a classe `Main.java`.
4. Utilize o menu do console para interagir com a aplicação.

Aprendizados:

O desenvolvimento deste projeto permite praticar encapsulamento, interfaces, composição, tratamento de exceções e aplicação de padrões de projeto sem dependência de frameworks.

Evoluções planejadas:

- Persistência em banco de dados.
- Testes automatizados.
- Relatórios e indicadores de doações.
- Novas estratégias de distribuição.
